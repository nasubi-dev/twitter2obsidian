# 動画のローカル保存

2026-11-14 に実装した（NAS-61）。画像の対応は [画像のローカル保存](画像のローカル保存.md)。

## 何をするか

動画ツイート（引用元の動画も）を保存するとき、動画ファイルを vault の `assets/twitter/<メディアID>.mp4` に書き込み、ノートに `![[...]]` で埋め込む。「Watch Video on X」のリンクは残す。frontmatter には `videos:`（引用元は `quoted_videos:`）として `"[[assets/twitter/<id>.mp4]]"` を並べる。

保存できなかったとき（API が落ちている、30MB 超、PUT 失敗）は、今までどおりリンクと iframe 埋め込みだけになる。ノートの保存は止めない。

## 動画の URL の取り方

X の画面の `<video>` は blob URL で、mp4 の URL は DOM から取れない。fxtwitter の公開 API `https://api.fxtwitter.com/status/<tweetId>` を引き、`.tweet.media.videos[].variants[]`（引用元は `.tweet.quote.media.videos`）から mp4 を選ぶ。variant の URL には `/<幅>x<高さ>/` が入っている。

メディア ID は URL の `ext_tw_video/<id>/`・`amplify_video/<id>/` の数字。GIF（`tweet_video/<name>.mp4`）は `<name>`。

## 形式・画質・上限（2026-11-14 計測）

35 秒の動画で比べた。

| | 720p | 360p |
|---|---|---|
| X の mp4 | 2.3MB | 0.67MB |
| VP9 の webm に変換（crf 40） | 3.3MB | 1.1MB |

X の mp4 はすでに強く圧縮されていて、webm に変換するとかえって大きくなった。変換はせず mp4 をそのまま保存する。

- 画質: 高さ 720 以下でいちばん高い variant。720 以下が無ければいちばん低いもの
- 上限: 30MB を超えたら保存しない（720p でおよそ 8 分）
- 2026-11-14 時点で動画ツイートのノートは 49 件。さかのぼって取り込むのは NAS-62
