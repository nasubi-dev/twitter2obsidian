# 動画のローカル保存

2026-11-14 に実装した（NAS-61）。画像の対応は [画像のローカル保存](画像のローカル保存.md)。

## 何をするか

動画ツイート（引用元の動画も）を保存するとき、動画ファイルを vault の `assets/twitter/<メディアID>.mp4` に書き込み、ノートに `![[...]]` で埋め込む。「Watch Video on X」のリンクは残す。frontmatter には `videos:`（引用元は `quoted_videos:`）として `"[[assets/twitter/<id>.mp4]]"` を並べる。

保存できなかったとき（API が落ちている、30MB 超、PUT 失敗）は、今までどおりリンクと iframe 埋め込みだけになる。ノートの保存は止めない。

## 動画の URL の取り方

X の画面の `<video>` は blob URL で、mp4 の URL は DOM から取れない。fxtwitter の公開 API `https://api.fxtwitter.com/status/<tweetId>` を引き、`.tweet.media.videos[].variants[]`（引用元は `.tweet.quote.media.videos`）から mp4 を選ぶ。variant の URL には `/<幅>x<高さ>/` が入っている。

メディア ID は URL の `ext_tw_video/<id>/`・`amplify_video/<id>/` の数字。GIF（`tweet_video/<name>.mp4`）は `<name>`。

## 形式・画質・上限（2026-11-14 計測）

35 秒の動画で比べた。

| | 720p | 360p |
|---|---|---|
| X の mp4 | 2.3MB | 0.67MB |
| VP9 の webm に変換（crf 40） | 3.3MB | 1.1MB |

X の mp4 はすでに強く圧縮されていて、webm に変換するとかえって大きくなった。変換はせず mp4 をそのまま保存する。

- 画質: 高さ 720 以下でいちばん高い variant。720 以下が無ければいちばん低いもの
- 上限: 30MB を超えたら保存しない（720p でおよそ 8 分）
- 2026-11-14 時点で動画ツイートのノートは 49 件。さかのぼって取り込むのは NAS-62

## 既存ノートの取り込み（NAS-62）

拡張が動画を保存する前のノートは、`scripts/localize-videos.mjs` で同じ形に揃える。使い方は `localize-images.mjs` と同じで、対象フォルダ以下を再帰的に見る。

```sh
node scripts/localize-videos.mjs --vault ~/Documents/obisidian/Clippings          # ドライラン
node scripts/localize-videos.mjs --vault ~/Documents/obisidian/Clippings --apply  # 書き込み
```

- 「Watch Video on X」を含むノートの `source:` のツイート ID で fxtwitter を引き、拡張と同じ規則で mp4 を保存する。本文の `<iframe>` を `![[…mp4]]` に置き換え、`videos:` を足す
- 引用元の動画は、引用部分の「Watch Video on X」の行の下に埋め込み、`quoted_videos:` を足す（もとの引用部分には iframe が無い）
- ポストが消えている（API が 404）ときは `<iframe>` のまま残し、`videos_lost: true` を付ける。30MB 超は印を付けずに残す
- 動画のサムネイルが frontmatter に無ければ、`thumbnail_url` を webp で保存して `images:` と `image_urls:` に足す。投稿者が付けたサムネイルは `_video_thumb` ではなく `media/` にあるので、URL の形ではなくメディア ID がノートにあるかで判断する
- 何度流しても同じ結果になる。`videos:` / `quoted_videos:` があるノートは動画を取り直さない

### 2026-11-15 の実行結果

対象 49 件のうち、取り込み済みの 1 件を除く 48 件を書き換えた。

| | 件数 |
|---|---|
| 保存した動画 | 48 本（112.9MB） |
| 保存したサムネイル | 11 枚 |
| 30MB 超 | 0 |
| 消えていた（`videos_lost: true`） | 2 件（Naoki Iso、tsukushi） |
| 本体に動画が無く、引用元にだけあった | 2 件（izm、雨音ウタ） |

最後の 2 件は、引用元の動画を拡張が本体の動画と取り違えて保存したノート。本体には動画が無いので、`quoted_videos:` だけを足し、本体の `<iframe>` は残した（ポストは生きているので、iframe には引用元の動画ごと表示される）。

Evan のノートは投稿者が付けたサムネイル（`media/`）が `images:` にすでにあったので、サムネイルは足していない。
