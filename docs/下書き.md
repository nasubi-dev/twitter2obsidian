## やりたいこと

Twitter(X)でツイートを見ているときに拡張機能のアイコンをクリックすると、自動的に Obsidian の`/Clippings/twitter`フォルダにツイートが保存される。プロパティにはツイートの URL と投稿に含まれている画像を Frontmatter に含める。

最終的な目的は、従来のブックマークが使いづらいため、Obsidian の Bases を用いて一覧表示・検索する。

## 要件定義

### 保存されるマークダウンファイルの仕様

- **ファイル名**: `{author}-{tweet_id}.md` (例: `Elon Musk-1991158519911874984.md`)
- **保存先**: `Clippings/twitter/` フォルダ（設定で変更可能）
- **Frontmatter (Properties)**:
  ```yaml
  ---
  source: https://x.com/username/status/1234567890
  author: Display Name
  text: ツイートの本文がここに入ります
  date: 2025-01-15
  images:
    - https://pbs.twimg.com/media/xxxxx?format=jpg&name=large
    - https://pbs.twimg.com/media/yyyyy?format=jpg&name=large
  ---
  ```
- **本文**:
  - ツイートテキスト
  - 動画の場合: 🎥 動画リンク + iframe 埋め込み
  - 画像の場合: マークダウン形式の画像表示

### 拡張機能の機能要件

1. **単一ツイートの保存**

   - Twitter/X の個別投稿ページ（`https://x.com/*/status/*`）で URL バーのアイコンをクリック
   - キーボードショートカット（`Alt+O`）で保存
   - 現在表示中のツイート情報を取得して Obsidian に保存
   - 保存済みの場合はトースト通知を表示（重複保存しない）
   - 動画ツイート対応（サムネイル、動画リンク、iframe 埋め込み）

2. **設定画面**

   - `about:addons` の拡張機能設定タブで管理
   - Obsidian Local REST API のエンドポイント（デフォルト: `https://127.0.0.1:27124`）
   - API キー
   - 保存先フォルダパス（デフォルト: `Clippings/twitter`）
   - システム通知 ON/OFF
   - 接続テスト機能

3. **トースト通知**
   - ページ内に保存状態を表示（⏳ 保存中、✅ 成功、❌ エラー、ℹ️ 既存）
   - アニメーション付きの視覚的フィードバック

### 技術仕様

- **対象ブラウザ**: Firefox (Manifest V2)
- **API**: Obsidian Local REST API
- **パーミッション**:
  - `storage` (設定保存)
  - `notifications` (システム通知)
  - `tabs` (タブ管理)
  - `https://x.com/*`, `https://twitter.com/*` (Twitter/X へのアクセス)
  - `https://127.0.0.1/*`, `https://localhost/*` (Local REST API 通信)
- **UI**:
  - `page_action` (URL バーアイコン - ツイートページでのみ表示)
  - `options_ui` (about:addons 設定ページ)
  - トースト通知（content script 内）
- **ショートカット**: `Alt+O` でツイート保存

## 技術調査結果サマリー

### Obsidian Local REST API の使用方法

**API エンドポイント**: `https://127.0.0.1:27124` (デフォルト)

#### 主要な API 仕様

1. **ファイル作成・更新**: `PUT /vault/{path}`

   ```javascript
   fetch("https://127.0.0.1:27124/vault/Clippings/twitter/twitter-123456.md", {
     method: "PUT",
     headers: {
       Authorization: "Bearer YOUR_API_KEY",
       "Content-Type": "text/markdown",
     },
     body: markdownContent,
   });
   ```

2. **ファイル存在確認**: `GET /vault/{path}`

   - 存在する場合: 200 OK (ファイル内容を返す)
   - 存在しない場合: 404 Not Found

3. **ファイル一覧取得**: `GET /vault/`
   - vault 内の全ファイルリストを取得

### Twitter/X の DOM 構造 (2025 年 11 月時点)

#### ツイート情報の取得セレクタ

```javascript
// ツイート要素
const tweetSelectors = [
  'article[data-testid="tweet"]',
  'article[role="article"]',
];

// ツイート本文
const textSelector = '[data-testid="tweetText"]';

// 著者名（表示名）
const usernameSelectors = ['[data-testid="User-Name"] span'];

// 画像要素
const imageSelectors = [
  'div[data-testid="tweetPhoto"] img',
  'a[href*="/photo/"] img',
  'img[src*="pbs.twimg.com/media"]',
];

// 動画要素
const videoSelector = '[data-testid="videoPlayer"]';
const videoThumbnail = "video[poster]"; // poster属性からサムネイル取得

// 投稿日時
const timestampSelector = "time[datetime]";

// ツイートURL (status ID)
// window.location.pathname から /status/(\d+) を抽出
```

#### 注意点

- Twitter/X は頻繁に DOM 構造を変更するため、複数のフォールバックパターンが必要
- 動的読み込みのため、`MutationObserver`または`setTimeout`での待機が必要

### Firefox 拡張機能の実装方法

#### Manifest V2 (Firefox)

```json
{
  "manifest_version": 2,
  "name": "Twitter to Obsidian",
  "version": "1.0.0",
  "permissions": [
    "storage",
    "notifications",
    "tabs",
    "https://x.com/*",
    "https://twitter.com/*",
    "https://127.0.0.1/*",
    "https://localhost/*"
  ],
  "commands": {
    "save-tweet": {
      "suggested_key": {
        "default": "Alt+O"
      },
      "description": "Save current tweet to Obsidian"
    }
  },
  "page_action": {
    "default_icon": "icons/favicon.ico",
    "default_title": "Save tweet to Obsidian",
    "show_matches": ["*://x.com/*/status/*", "*://twitter.com/*/status/*"]
  },
  "options_ui": {
    "page": "options.html",
    "browser_style": true
  },
  "background": {
    "scripts": ["background.js"]
  },
  "content_scripts": [
    {
      "matches": ["*://x.com/*", "*://twitter.com/*"],
      "js": ["content.js"],
      "run_at": "document_idle"
    }
  ]
}
```

#### browser API (Firefox)

- `browser.storage.sync` で設定保存
- `browser.tabs.sendMessage()` / `browser.runtime.sendMessage()` でメッセージング
- `browser.notifications` でシステム通知表示
- `browser.pageAction` で URL バーアイコン制御
- `browser.commands.onCommand` でショートカットキー処理
- トースト通知は content script 内で DOM 操作

### 重複チェックの実装方針

**採用方法**: ファイル名ベースのチェック (Local REST API 使用)

1. ツイート ID を URL から抽出
2. ファイル名を生成: `{author}-{tweet_id}.md` (例: `Elon Musk-1234567890.md`)
3. `GET /vault/{folderPath}/{filename}.md` で存在確認
4. 404 エラーの場合のみ新規保存、200 の場合は「Already Saved」と通知

**メリット**:

- 高速（ファイル内容を読まない）
- 実装がシンプル
- 確実（ファイル名が一意）
- 著者名を含むことで視認性が向上

## 前提条件

### ユーザーが事前にインストール・設定が必要なもの

1. **Obsidian Local REST API プラグイン**

   - Obsidian のコミュニティプラグインからインストール
   - API キーを生成（Settings > Local REST API）
   - HTTPS を有効化（自己署名証明書）

2. **Firefox 拡張機能の設定**
   - `about:addons` → Twitter to Obsidian → 設定タブ
   - API エンドポイント: `https://127.0.0.1:27124` (デフォルト)
   - API キーを入力
   - 保存先フォルダパス: `Clippings/twitter` (デフォルト)
   - Test Connection で接続確認
   - システム通知の ON/OFF 設定
